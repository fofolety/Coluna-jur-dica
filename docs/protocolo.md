# Protocolo de Operação – Geração de Coluna

Para solicitar a criação de uma nova coluna utilizando esta estrutura, utilize o seguinte comando/prompt padrão:

> **"Com base na estrutura do Projeto 02, quero redigir uma coluna para a revista.**
> - **Tema / Ideia:** [Descreva aqui]
> - **Narrativa / Caso ilustrativo:** [Descreva aqui]
> - **Objetivo da coluna:** [O que o leitor deve entender/decidir ao final]"

## Passos executados pela estrutura:
1. Leitura do `apoio/guia_estilo_revista.md` para validação de tom e tamanho.
2. Estruturação do roteiro do artigo.
3. Redação completa do rascunho.
4. Salvamento do arquivo resultante na pasta `saida/rascunhos/coluna-[tema-resumido].md`.
5. Apresentação do rascunho na tela para sua revisão final.
